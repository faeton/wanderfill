# `wanderfill history` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** a read-only `history` command answering visa / ESTA / tax / absence / "where was I" questions from profile + track, cross-checked.

**Architecture:** `countries.py` (ISO table, groups, region→country map) and `history.py` (pure ledger + queries + renderers) under test; `cli/main.py` only loads inputs and writes files.

**Tech Stack:** Python 3.11 stdlib, pytest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-06-history-design.md`

## Global Constraints

- Read-only on NomadMania: no write method of `NomadMania` may be called from this code path.
- Never drop: undated claims → CHECK rows; airborne-only → overflight list; "no" always qualified by coverage.
- Never bridge across different countries; default `--bridge 7`; `--territories separate` default.
- Every output starts with the header block (command, today, window, expanded groups, flags, coverage).
- Output dir `history/` gitignored.
- Region→country via `flag1` then `flag2` against `countries()` rows (as `yes_scores`); every NM country must map to ISO or the run stops.

## Review Focus

1. Profile visit with `date_to` None or before `date_from` → expand to `date_from` only, never crash or invert.
2. Window boundaries: trip straddling `--since` is reported (clipped, marked "began before window").
3. Track and photos both present for the same day → one ledger row, two sources, not double-counted days.
4. `--home` given as a group/unknown code → error, not silent empty result.
5. Empty ledger (no sources cover window) → output says so with coverage, not an empty "no" table.
